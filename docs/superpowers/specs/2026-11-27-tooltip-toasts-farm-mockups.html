Holdings in the tooltip

Every item and currency tooltip lists who on the account holds it and where. The logged-in character reads live from the client. Everyone else, and the Warband, reads from the holdings ledger.

Public API for other addons new

-- published as _G.LootHistory = { API = NS.API } -- (the standard's public-api rule; v1 is semver-stable) local api = LootHistory and LootHistory.API.v1 api.Version() --> 1 api.Holders() --> { "Charone-Realm", …, "§warband" } api.HolderInfo(holder) --> { name, realm, class, -- isWarband, lastSeen, partial } api.ItemCount(itemID) --> total, { [holder] = -- { bags=12, bank=40, … } } api.CurrencyCount(id) --> total, { [holder] = n } api.Money(holder?) --> copper (nil = all) api.Holdings(holder) --> read-only copy of one holder api.Scanned(holder) --> { bags=ts, bank=ts, … } -- change notifications api.RegisterCallback(owner, "HoldingsChanged", fn) api.UnregisterCallback(owner, "HoldingsChanged") -- fn(event, holder)
  • Every answer is a copy, so another addon can't write into the saved data.
  • The logged-in character's counts are the same live ones the tooltip uses.
  • It answers nil or empty while holdings tracking is off, and while the addon is disabled.
  • The contract is documented in ARCHITECTURE.md. A breaking change later would ship as v2 alongside v1.

#38

Loot toasts

Feeds of every gain the addon sees: items, money, currencies, reputation, appearances, experience and profession skill-ups. They read gains before the capture filters and the minimum quality. One feed is on by default, and you can add up to three. Each feed has its own slot on screen, its own kinds and filters, and its own look. The look follows the skin unless you override it.

#39

Farm mode

You start a session, farm, then finish it and get a summary with gold per hour and an activity tally. It counts gains from the same feed as the toasts. Costs come from the loss rows History records. A /reload or a disconnect keeps the session going. Logging out finishes it, and every finished session is saved in full.
